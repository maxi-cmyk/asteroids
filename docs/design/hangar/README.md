# Hangar showroom layout

Selected 2026-11-23: [showroom-reference.png](showroom-reference.png). This replaces the
centered-carousel composition. The reference controls layout; the in-game pixel hulls
replace its smoother illustrations.

- Left: selected option, campaign requirement, real stats and accent colour swatches.
- Right: one large ship preview, with arrows. Test loadout opens the practice range here.
- Below: six thumbnail cards with equipped/preview/locked states. Ships and weapons each
  have their own pixel art; there is no slider.
- Bottom: three independent equipped slots, a separate Equip action and Test loadout.

Browsing, including horizontal scrolling over the preview or cards, does not equip items.
Locked choices can be previewed; the bottom dock keeps showing the saved build. The outer
frame and preview background stay transparent to the Hangar surface.
